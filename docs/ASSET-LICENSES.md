# Asset register

- Equipment camera/projector/computer/ball illustrations: original editable SVG React drawings authored for this repository in `src/components/EquipmentArt.tsx`. Generic category illustrations, not photographs of the actual inventory. Newly added equipment uses a category fallback.
- Brand shelf mark: typographic mark and layout authored in this repository; no external logo.
- Barlow Semi Condensed, IBM Plex Sans and Noto Sans Thai: self-hosted through their `@fontsource/*` npm packages. Fontsource packages include font licenses; preserve license files when redistributing font assets. Upstream font families are distributed under the SIL Open Font License. See installed package LICENSE files and lockfile for exact revisions.
- No scraped equipment photographs, testimonials, external stock imagery or real-person portraits are included.

The illustration approach is an explicit fallback from the proposed photography direction: no licensed product photos were supplied. It avoids representing a generic photo as a specific inventory item.
